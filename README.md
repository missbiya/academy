## Quick GitHub Pages Deployment Steps (`Miss-biya-academy`)
1. Go to **https://github.com/new** and create a **Public** repository named **`Miss-biya-academy`**.
2. Upload `index.html`, `.nojekyll`, and `README.md` to the root of the `Miss-biya-academy` repository and click **Commit changes**.
3. Open **Settings -> Pages** in your repository, set **Branch** to **`main`** (`/root`), and click **Save**.
4. In ~30–60 seconds, your website will be live at **`https://missbiya.github.io/Miss-biya-academy/`**.
